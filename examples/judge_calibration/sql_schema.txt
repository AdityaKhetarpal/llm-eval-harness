SQLite database of an Indian online shop. Money is in Indian rupees (INR).

TABLE customers -- one row per customer
  customer_id INTEGER
  name TEXT
  city TEXT  -- e.g. 'Jaipur', 'Hyderabad', 'Kochi', 'Ahmedabad', 'Mumbai', 'Guwahati', 'Bengaluru', 'Indore'
  state TEXT  -- e.g. 'Rajasthan', 'Telangana', 'Kerala', 'Gujarat', 'Maharashtra', 'Assam', 'Karnataka', 'Madhya Pradesh'
  segment TEXT  -- e.g. 'Consumer', 'Business'
  signup_date TEXT  -- text 'YYYY-MM-DD'

TABLE products -- one row per product in the catalogue
  product_id INTEGER
  product_name TEXT
  category TEXT  -- e.g. 'Electronics', 'Fashion', 'Home & Kitchen', 'Beauty', 'Books', 'Grocery', 'Sports'
  brand TEXT  -- e.g. 'Saffron', 'Nova', 'Urban Leaf', 'Vega', 'Kiran', 'Orbit', 'Lotus', 'Zenith'
  list_price_inr INTEGER  -- catalogue price in rupees

TABLE orders -- one row per order (an order can contain several products)
  order_id INTEGER
  customer_id INTEGER
  order_date TEXT  -- text 'YYYY-MM-DD'
  delivery_date TEXT  -- text 'YYYY-MM-DD', empty (NULL) if cancelled or not delivered yet
  status TEXT  -- e.g. 'delivered', 'returned', 'cancelled', 'shipped'
  payment_method TEXT  -- e.g. 'Card', 'Cash on Delivery', 'UPI', 'Net Banking', 'Wallet'

TABLE order_items -- one row per product line inside an order
  order_item_id INTEGER
  order_id INTEGER
  product_id INTEGER
  quantity INTEGER
  unit_price_inr INTEGER  -- price of ONE unit in rupees before discount
  discount_pct INTEGER  -- discount on this line, 0-30 (percent)

JOINS: orders.customer_id = customers.customer_id; order_items.order_id = orders.order_id; order_items.product_id = products.product_id

BUSINESS DEFINITIONS:
- Today is 2026-10-01. Data runs from 2025-01-01 to 2026-09-30. 'Last month' = September 2026 only (order_date LIKE '2026-09%'); 'this year' = 2026; 'last year' = 2025.
- Line revenue = quantity * unit_price_inr * (1 - discount_pct / 100.0).
- Revenue (or sales) = sum of line revenue for orders with status IN ('delivered', 'shipped'). Cancelled and returned orders are NOT revenue. Every revenue query MUST join orders and filter on status.
- Valid orders = orders with status IN ('delivered', 'shipped').
- 'Orders' or 'orders placed' with no status mentioned = ALL orders, whatever their status. Same for 'customers who placed an order'.
- Average order value (AOV) = revenue / COUNT(DISTINCT order_id) of valid orders.
- Return rate = returned orders / (all orders that were not cancelled) * 100. Count ORDERS (COUNT(DISTINCT order_id)), not order lines.
- Cancellation rate = cancelled orders / all orders * 100.
- Units sold = sum of quantity on valid orders.
- Delivery time = julianday(delivery_date) - julianday(order_date), in days, for delivered orders.
- city, state and segment are columns of customers (join orders -> customers). category, brand and product_name are columns of products (join order_items -> products). status and payment_method are columns of orders.
- Months: use substr(order_date, 1, 7) to get 'YYYY-MM'. Percentages are 0-100, not 0-1. Round money to 2 decimals.
- To count things per group and then filter (e.g. customers with more than N orders), use a subquery: SELECT COUNT(*) FROM (SELECT ... GROUP BY ... HAVING ...).
